# Reboot Sequence project content

The learner project is split into 21 small, testable steps. Each step adds no more than two closely related pieces of functionality.

```plaintext
en/
├── images/
│   └── .keep
├── resources/
│   └── .keep
├── solutions/
│   ├── .keep
│   └── reboot-sequence.ts
├── README.md
├── meta.yml
├── step_1.md
├── ...
└── step_21.md
```

The project uses Microsoft MakeCode for micro:bit. Fenced `blocks` snippets contain MakeCode TypeScript that can be rendered as blocks by a compatible Markdown processor.

The project is currently an authoring draft. `solutions/reboot-sequence.ts` records the intended completed MakeCode logic, but a downloadable MakeCode project and the required photographs must still be produced and tested on physical BBC micro:bit V2 hardware before publication. See [the project specification](../PROJECT_SPEC.md) for the acceptance criteria and asset list.
