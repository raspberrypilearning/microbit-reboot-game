# Reboot Sequence project content

The learner project has 19 short milestones. It builds and tests the game with bare leads before making the wearable controls. The optional symbols challenge comes last.

`meta.yml` lists the steps. `step_1.md` to `step_19.md` hold the learner copy. `solutions/reboot-sequence.ts` records the completed default game, with a code length of five. Learners can choose another positive whole-number length.

The project uses Microsoft MakeCode for micro:bit. Fenced `microbit` snippets contain MakeCode TypeScript, which Raspberry-flavoured Markdown renders as blocks. Inline toolbox and block names use the corresponding micro:bit category styles.
